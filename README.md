# hxyfront-62001 轮机舱底水排放台

面向船舶轮机值班的舱底水排放控制台，登记舱底水位、油分浓度、排放泵出口压力和阀门开度。

## 业务规则

- 水位超过警戒线（1.5m）时必须启动备用排放泵
- 油分浓度高于 15ppm 或排放阀未全开时整次拒绝，原水位与泵状态不变
- 泵连续两次出口压力越界（正常 0.20–0.60MPa）自动停机并生成待复核项，复核关闭后泵复位
- 本班存在未关闭复核项不得完成交接
- 历史记录只追加不改写，数据保存在浏览器本地（localStorage），刷新保留

## 技术栈

React + Vite + TypeScript
