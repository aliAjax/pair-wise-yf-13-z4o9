# 轮机舱底水排放台（hxyfront-62001）

面向船舶轮机值班的舱底水排放登记与安全联锁控制台。

## 功能

- **排放登记**：登记舱底水位、油分浓度、排放泵出口压力、阀门开度（随每次登记快照入档）
- **安全联锁规则**
  - 水位超过警戒线 → 必须启动备用排放泵
  - 油分浓度 > 15ppm 或排放阀未全开 → 整次拒绝，原水位与泵状态不变
  - 泵连续两次出口压力越界（正常 0.15–0.45MPa）→ 自动停机并生成待复核项，复核关闭前该泵不可再次启动
  - 本班存在未关闭复核项 → 不得完成交接
- **参数看板**：水井液位（含警戒线）、泵状态、阀门开度、油分浓度、班次统计与交接
- **历史记录**：按设备筛选的时间线，只追加不改写
- **本地存储**：状态（含筛选条件）同步至 localStorage，刷新保留

## 技术栈

React + Vite + TypeScript（业务规则集中在 `src/domain.ts` 纯函数中）
